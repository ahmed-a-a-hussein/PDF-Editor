
# PDF Editor

A Python-based PDF editor for managing and converting PDF files through an interactive Jupyter Notebook interface.

## Features

- Merge multiple PDF files
- Split PDF documents
- Compress PDF files
- Convert PDF pages to JPG images
- Convert JPG images to PDF
- Reorder PDF files before processing

## Technologies

- Python
- PyMuPDF
- Pillow
- ipywidgets
- Jupyter Notebook

## How to Use

1. Download `PDF_Editor.ipynb`.
2. Open it in Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook and use the interactive interface to process your files.
